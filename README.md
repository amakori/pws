# Locker Door Controller PWA 🚪⚡

A Progressive Web App (PWA) that connects directly to Supabase to trigger locker door state transitions.
Pressing the single tactile action button sets `door_id = 7`, initiates a 10-second countdown with visual/haptic feedback, and automatically updates `door_id = 8`.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Supabase Credentials
You can configure credentials in either of two ways:

#### Option A: In-App UI (No code changes needed)
1. Run the app (`npm run dev`).
2. Click the ⚙️ **Settings** gear icon in the top right.
3. Paste your **Supabase Project URL** and **Anon Public Key**.
4. Click **Test Connection** and **Save Settings**. (Saved securely in your browser's `localStorage`).

#### Option B: `.env` file
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
And add your credentials:
```env
VITE_SUPABASE_URL=https://<your-project-id>.supabase.co
VITE_SUPABASE_ANON_KEY=<your-anon-key>
VITE_DEFAULT_LOCKER_ID=LOCKER-1
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🗄️ Database Setup (Supabase SQL)

Ensure your `public.locker_commands` table exists in Supabase:

```sql
create table if not exists public.locker_commands (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  door_id bigint null,
  locker_id text null,
  processed boolean null,
  job_id uuid null default gen_random_uuid (),
  sender text null,
  receiver text null,
  command text null,
  package_id bigint null,
  company_id uuid null,
  constraint locker_commands_pkey primary key (id)
) TABLESPACE pg_default;
```

### Row Level Security (RLS) Policy
If Row Level Security (RLS) is enabled on `locker_commands`, ensure anonymous access is allowed:

```sql
alter table public.locker_commands enable row level security;

create policy "Allow anon insert, select, and update" 
on public.locker_commands 
for all 
to anon 
using (true) 
with check (true);
```

### Realtime Updates (Optional but Recommended)
To enable live feed updates without page refreshes:
1. Go to **Supabase Studio ➔ Database ➔ Publications**.
2. Ensure `public.locker_commands` is added to `supabase_realtime`.
Or run:
```sql
alter publication supabase_realtime add table public.locker_commands;
```

## 📱 How It Works

1. **Button Press**:
   - Depending on the selected mode (*Insert New Command* or *Update Latest Row*), sets `door_id = 7`.
   - The button transitions to active amber state with pulse glow.
   - Haptic feedback is triggered on supported mobile devices.
2. **10-Second Countdown**:
   - The circular SVG progress ring animates smoothly down from 10.0s to 0.0s.
   - Displays real-time countdown digits and target row ID.
3. **Transition to Door 8**:
   - At exactly 10 seconds, the app updates that row's `door_id = 8` and marks `processed = true`.
   - The button pulses green with celebration confetti and haptic buzz.
   - The live activity feed automatically updates.
   - After 3 seconds, the button resets to the ready state.

## 📲 PWA Installation

- **Android / Chrome**: Tap the "Install" banner or the browser menu (⋮) ➔ **"Install app"** / **"Add to Home screen"**.
